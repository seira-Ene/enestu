# 第3週 利用者検証の記録

第4週のピボットの根拠にする。名前は書かず「友人A」「友人B」とする。

## 進め方（1人15分ほど）

1. <https://enestu.vercel.app> を、本人のスマホで開いてもらう。
2. 次を伝える。
   - 認証がまだないため、個人情報や人に見られて困る内容は入力しない。
   - うまく使えないのはアプリの問題なので、思ったことをそのまま口に出してほしい。
3. 下の課題を順に頼む。**操作は教えず、迷った場所を観察して書き留める。**
4. 最後に質問する。

## 課題

| # | 頼むこと | 見る点 |
|---|---|---|
| 1 | 何か1科目を1分ほど計測して記録する | 開始・停止に迷わないか |
| 2 | 最近学んだことをカードに3枚登録する | 入力が面倒そうか、どこで手が止まるか |
| 3 | テストで3枚を解く（1問はわざと間違える） | 自動判定に納得するか、原因を選ぶか |
| 4 | 苦手な科目と、今日やるべきことを言ってもらう | 集計とクエストの意味が伝わるか |

## 聞き取った指摘（2名分）

課題ごとの結果、端末、誰の指摘かは記録していない。

| # | 指摘 |
|---|---|
| 1 | 5つの世界線をどうやって行き来すればよいかわからない |
| 2 | デザインがチープでやる気が起こらない、やってて面白くない |
| 3 | フォントもちゃんとその世界線に合ったものを使ってほしい |
| 4 | いちいち問題を自分で入力するしかないからめんどくさい |

## まとめ（第4週の判断）

| 指摘 | 対応 | 理由 |
|---|---|---|
| 1 | 4-1で直す：初回の選択画面と、全画面の右上に切り替えボタン | 検証時は切り替えが未実装だった。中核的価値そのもの |
| 2（チープ） | 4-1で直す：世界線ごとの背景・枠・キャラ絵・演出 | 1・3と同じテーマ定義で直せる |
| 3 | 4-1で直す：世界線ごとの日本語フォント | 同上 |
| 4 | 4-2で直す：まとめて取り込み、カードの編集・削除 | 毎日使えるかに直結する |
| 2（面白くない） | 4-3で試す：連続正解の演出とレベルアップ | 何が退屈かは未確認のため、小さく試す |

- 最優先に直すこと：世界線の切り替えと、世界観に合ったデザイン
- 計画から変えること：世界線の切り替えだけの予定を、デザインの作り直しと入力の手間の削減まで広げる
- 見送ること：AIによる問題生成。規約の年齢条件と、認証がないことが理由（`docs/design/ai-question-generation.md`）
- 次に確かめること：どの場面で退屈だったか
