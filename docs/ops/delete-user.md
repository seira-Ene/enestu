# 利用者を削除する手順

退会の依頼を受けたときに行う。本番のデータを消すので、その都度、開発者が行う。

## 1. 写真を消す

写真はデータベースではなくStorageにあり、利用者を消しても残る。先に消す。

1. Supabaseのダッシュボードで **Authentication → Users** を開き、利用者のUser UIDを控える。
2. **Storage → notes** を開く。
3. User UIDと同じ名前のフォルダを選び、中の写真をすべて削除する。

## 2. 利用者を消す

1. **Authentication → Users** で利用者の行を開き、**Delete user** を押す。
2. 学習の記録、カード、解答、用語、説明、メモ、設定は、データベースの設定で一緒に消える。

## 3. 確かめる

- **Storage → notes** に、そのUser UIDのフォルダが無い。
- **Authentication → Users** に、その利用者がいない。

## 注意

- ログインせずに使った端末のデータは、利用者とひも付いていないので、この手順では消えない。ログインして取り込んだ分は消える。
